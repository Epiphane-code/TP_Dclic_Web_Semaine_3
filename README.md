# TP DCLIC — Semaine 3

## 📚 Présentation

Ce dépôt contient les travaux pratiques réalisés dans le cadre de la **formation DCLIC**, semaine 3.

L'objectif de ce TP est de renforcer les bases du **développement Web** à travers plusieurs exercices portant sur la création et la structuration de pages HTML, l'intégration d'images, les listes, les tableaux ainsi que la réalisation d'une page de synthèse.

## 📝 Description des exercices

### Exercice 1 — Structure HTML

Création d'une première page Web afin de mettre en pratique la structure de base d'un document HTML.

**Compétences travaillées :**

* Structure d'une page HTML
* Utilisation des balises HTML
* Titres et paragraphes
* Organisation du contenu

---

### Exercice 2 — Page Web

Réalisation d'une nouvelle page HTML permettant de poursuivre la pratique de la structuration et de l'organisation du contenu Web.

**Compétences travaillées :**

* Organisation du contenu
* Utilisation des différentes balises HTML
* Structuration d'une page

---

### Exercice 3 — Images

Cet exercice porte sur l'intégration d'images dans une page Web.

Les ressources graphiques sont regroupées dans le dossier :

```text
assets/images/
```

**Compétences travaillées :**

* Utilisation de la balise `<img>`
* Chemins relatifs
* Organisation des ressources
* Intégration de contenus multimédias

---

### Exercice 4 — Listes

Création d'une page permettant de présenter des informations sous forme de listes.

**Compétences travaillées :**

* Listes ordonnées
* Listes non ordonnées
* Organisation des informations
* Utilisation des balises `<ul>`, `<ol>` et `<li>`

---

### Exercice 5 — Tableaux

Création d'un tableau HTML permettant de présenter des informations sous forme de lignes et de colonnes.

**Compétences travaillées :**

* Création d'un tableau
* Lignes et cellules
* En-têtes de tableau
* Organisation des données

---

### Exercice 6 — Synthèse

Réalisation d'une page de synthèse regroupant les différentes notions étudiées durant le TP.

Cet exercice permet de consolider les connaissances acquises dans les exercices précédents.

## 🚀 Utilisation

Aucune installation particulière n'est nécessaire.

Il suffit de cloner le dépôt :

```bash
git clone https://github.com/Epiphane-code/TP_Dclic_Web_Semaine_3.git
```

Puis d'ouvrir les fichiers `.html` dans un navigateur Web.

Par exemple :

```text
Exercice1/index.html
Exercice2/index.html
Exercice3/images.html
Exercice4/liste.html
Exercice5/tableau.html
Exercice6/synthese.html
```

## 🎯 Objectifs pédagogiques

À travers ce TP, les objectifs sont de :

* comprendre la structure d'une page HTML ;
* utiliser correctement les balises HTML ;
* organiser les fichiers d'un projet Web ;
* intégrer des images ;
* créer et manipuler des listes ;
* créer des tableaux ;
* réaliser une page regroupant plusieurs notions ;
* apprendre à versionner un projet avec Git ;
* publier un projet sur GitHub.

---

## 📌 Conclusion

Ce TP constitue une étape importante dans l'apprentissage du développement Web. Les différents exercices permettent de maîtriser progressivement les éléments fondamentaux nécessaires à la création de pages Web structurées et organisées.

Les notions acquises pourront ensuite être approfondies avec **CSS** pour améliorer l'apparence des pages et **JavaScript** pour ajouter de l'interactivité.
